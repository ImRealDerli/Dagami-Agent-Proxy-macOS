# Dagami mac.25 beta — код Antigravity CLI

Исправлено получение кода с официальной страницы возврата: она очищает query-параметры ещё до опроса Selenium. Dagami сохраняет привязку к OAuth state в изолированном контексте своего браузера до выполнения скрипта страницы и читает блок data-code-box. Чужая сессия код не получает.

Служебные ответы Terminal и события фокуса больше не считаются ручным вводом. Код передаётся в PTY соответствующего CLI, затем отдельным событием отправляется Enter. Настоящий ручной ввод и Escape приостанавливают автоматику. В журнал добавлены этапы cliAuth без кода и OAuth-ссылок.

После замены Dagami.app откройте новую CLI-сессию через Dagami. Уже работающий терминальный процесс продолжит использовать прежний перехват. В скрытом поле CLI символы кода не отображаются — так работает сам клиент.

276 локальных тестов прошли. Дополнительно проверена связка Selenium → страница с немедленной очисткой URL → скрытый ввод собственного PTY → Enter во встроенном Python. Вход в живой аккаунт пользователя не выполнялся.

macOS 13+, Intel и Apple Silicon. Сборка с ad-hoc подписью, без нотарификации Apple. Исходная основа: https://github.com/j46871417-ui/Dagami-Agent-Proxy. Инструкция и ограничения — в README этого форка.
