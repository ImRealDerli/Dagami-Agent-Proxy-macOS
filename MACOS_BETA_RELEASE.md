# Dagami для macOS — 0.4.0 mac.24 beta

Первый публичный выпуск macOS-порта. Основан на Dagami Agent Proxy; официальный проект: https://github.com/j46871417-ui/Dagami-Agent-Proxy. Порт и его сопровождение: https://github.com/ImRealDerli/Dagami-Agent-Proxy-macOS.

Для macOS 13+, Intel и Apple Silicon. Python для готового приложения отдельно не нужен.

В выпуск вошли профили подключения, Smart DNS, SwiftUI-интерфейс, журнал, подготовка совместимых клиентов и вход через выбранный профиль. Для Antigravity IDE 2.6.0 добавлен сетевой патч загрузчика CLI. Кнопка «Починить IDE» пересоздаёт подготовленную копию из оригинала с проверкой подписи. Перед закрытием работающих приложений требуется подтверждение.

## Скачать

- `Dagami-macOS-Universal.dmg` — установка через образ со ссылкой на «Программы».
- `Dagami-macOS-Universal.zip` — то же приложение в архиве.
- `Dagami-Full-Source.zip` — исходники порта.
- `SHA256SUMS.txt` — контрольные суммы архивов и образа.

Откройте DMG и перенесите Dagami.app в «Программы». При обновлении закройте предыдущую копию. Профили в ~/.devproxy и пароли в Keychain удалять не нужно. Подробная инструкция — в README.

## Проверено

272 теста с временными данными и loopback-серверами, целостность APP, строгая проверка подписи, контрольная сумма DMG. На отдельной копии официальной Antigravity IDE 2.6.0 проверены подготовка и откат.

## Ограничения беты

Сборка имеет ad-hoc подпись, без нотарификации Apple. Сетевой патч IDE подтверждён для 2.6.0; неизвестные версии не меняются. Для браузерного получения кода CLI в комплекте ChromeDriver 156. Доступность всех живых аккаунтов, моделей и регионов не проверялась. Smart DNS не меняет внешний IP. Совместимость самого Dagami с двумя архитектурами не делает ARM64-приложения совместимыми с Intel.

Если ошибка повторяется, приложите к issue версию macOS, тип процессора, версию клиента и обезличенный текст журнала. Не публикуйте реквизиты прокси и ссылки входа.
