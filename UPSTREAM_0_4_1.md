# Изменения официальной версии 0.4.1 beta на Mac

Выпуск macOS: **0.4.1 mac.27 beta**. Изменения тестовой версии включены в основную ветку `beta`.

Источник: [официальный выпуск](https://github.com/j46871417-ui/Dagami-Agent-Proxy/releases/tag/v0.4.1-beta), коммит `d03cee7e9659dc88e84f0bb8bb9639e1128c9477`.

В macOS перенесены HTTP framing и проверка владельца loopback-соединения из MIT-исходников upstream. Мост ограничивает число одновременно обслуживаемых соединений, возвращает 503 при перегрузке и не принимает соединения другого пользователя. Обычный HTTP обрабатывается по одной транзакции с Connection: close; сохранены потоковый RPC, chunked trailers и переключение протокола. Реквизиты upstream не передаются локальному backend.

Убраны конфликтующие proxy/PAC-флаги браузеров. Gemini CLI с внешним прокси получает отдельный маршрут без Smart DNS; сохранённый профиль не переписывается. Ошибка чтения настроек не приводит к молчаливому прямому подключению.

Повреждённые записи подготовленных приложений больше не считаются готовыми к запуску. Доступен откат или ремонт, а ошибка видна в интерфейсе. Обновлятор отказывается выполнять автоматическую установку от root. В отдельной тестовой сборке установка обновлений отключена; основная версия проверяет новые выпуски.

Windows-службы, Планировщик и Windows ACL не включены в Mac-приложение: используются существующие механизмы macOS. Изменение схемы лицензирования с подготовкой подписанных лицензий в upstream не означает включение нового сервера выдачи ключей. Текущая активация и Keychain этой сборки сохранены.

Новые локальные сведения о сессиях описаны в [SESSION_MONITORING.md](docs/SESSION_MONITORING.md).
