# Dagami Agent Proxy 0.4.1 mac.28 beta

Сетевой транспорт перенесён на Rust (Tokio/rustls). Интерфейс, профили, Keychain, квоты и прежние патчи сохранены.

- TCP/TLS обрабатываются отдельным нативным процессом. У него общий TLS-контекст, ограниченные буферы и тайм-аут подключения; адреса IPv6/IPv4 пробуются с резервированием.
- Устранён риск исчерпания штатного GUI-лимита macOS в 256 дескрипторов: лимит повышается только у сетевого процесса в пределах разрешённых прав. Добавлен TCP keepalive для долгих ответов.
- Проверены большие двусторонние потоки через HTTP, HTTPS и SOCKS5. Закрытие одной стороны не обрезает уже полученный ответ. Проверка сертификатов сохраняется.
- CONNECT повторяется один раз после обрыва или 502/503/504 до отправки клиентских данных. Неверная авторизация 407 и уже начатые запросы не повторяются.
- Smart DNS хранит несколько адресов, временно исключает отказавшие и объединяет одновременные запросы. Не меняет выбранных провайдеров или DNS в macOS.
- Ошибки upstream попадают в журнал. В настройках и подробностях новых сессий виден движок.

После установки перезапустите приложения через Dagami: открытые ранее сессии используют прежний транспорт. Это рекомендуемое обновление. Работающий сервер прокси и подходящий выходной IP по-прежнему необходимы; системный TUN не добавлялся, а клиенту, игнорирующему proxy-env, нужен отдельный адаптер.

В составе — Universal APP для Intel/Apple Silicon, DMG, ZIP, полные исходники и SHA-256. macOS 13+. Подпись ad-hoc, без нотарификации Apple.
