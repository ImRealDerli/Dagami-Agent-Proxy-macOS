# Dagami Agent Proxy 0.4.1 mac.27 beta

В эту версию вошли новый интерфейс и изменения, которые раньше проверялись в отдельном Dagami Test.

- Компактное окно и меню в строке macOS. Сверху — обзор, профили, приложения и сессии.
- Профили можно удалять; редактор загружает сохранённые DNS, переключатели и полную ссылку прокси. Активная сессия защищает профиль от удаления.
- Терминальные запуски отображаются отдельно и останавливаются по одному. Старые запуски видны без управления.
- В карточках сессий доступны модель, состояние работы, контекст и квоты, которые передаёт клиент. Полосы показывают оставшийся запас.
- Исправлен сбор квот и состояния Antigravity CLI: справка agy в stderr теперь распознаётся.
- Antigravity App/IDE передают активность через штатные hooks; квоты читаются у локального backend. Codex использует hooks и экспериментальный app-server для чтения лимитов.
- Исправлен отказ Keychain при сохранении ключа и запуске CLI. Пароли передаются системной утилите через stdin, без секретов в аргументах процесса; запись проверяется чтением.
- Журнал получил понятные названия, поиск и подробности ошибок. Логотипы сглажены для разных плотностей экрана.
- Из официального 0.4.1 beta перенесены исправления HTTP-моста, ограничения соединений, проверка пользователя loopback и очистка конфликтующих параметров запуска. Для Gemini CLI с внешним прокси используется отдельный маршрут.

После установки перезапустите CLI через Dagami. В Codex откройте `/hooks` и проверьте доверие к Dagami. Для активности Antigravity App/IDE нажмите «Подключить активность приложения» и перезапустите клиент. Работающие сессии при обновлении автоматически не закрываются.

Это рекомендуемое обновление, не обязательное. Квоты Antigravity App/IDE используют внутренний интерфейс, который может измениться; все живые аккаунты не проверялись. Тексты запросов, ответы и токены входа мониторинг не сохраняет. macOS 13+, Intel и Apple Silicon. Подпись ad-hoc, без нотарификации Apple.
