# Бета-линия macOS

Ветка `beta` — основная ветка macOS-порта. Готовые файлы публикуются в GitHub Releases с отметкой **Pre-release**. Пока стабильной линии нет.

Теги имеют вид `v0.4.0-mac.24-beta`: первая часть относится к базовой версии проекта, `mac.24` — к номеру macOS-сборки. Номер upstream не означает, что все его функции одинаково реализованы на Mac.

Перед выпуском проверяются исходники, тесты, Universal-сборка, подпись APP и целостность DMG. В описании выпуска перечисляются проверенные сценарии и известные ограничения. Предыдущие GitHub-релизы могут понадобиться для возврата к рабочей версии; рабочие тестовые сборки туда не загружаются.

## Первый выпуск: mac.24

- Профили, локальный мост, Smart DNS и системные DNS-настройки macOS.
- SwiftUI-интерфейс, журнал, подтверждение закрытия процессов.
- Отдельные адаптеры Antigravity App, IDE и CLI.
- Сетевой патч Antigravity IDE 2.6.0 и кнопка «Починить IDE».
- Вход CLI через отдельный браузер и Selenium.
- ChatGPT Desktop и отдельная веб-версия, проверка архитектуры приложений.

Результаты проверки: 272 теста; строгая проверка подписи APP и контрольная сумма DMG. Живые аккаунты всех продуктов не проверялись. Поддержка IDE 2.6.0 не означает поддержку произвольной будущей сборки.

## mac.25

Исправлен перехват кода после очистки адресной строки официальной страницей возврата. Служебные события Terminal не блокируют автоввод. Код и Enter направляются в PTY соответствующей CLI-сессии; ручной ввод по-прежнему защищён. После обновления нужна новая CLI-сессия через Dagami.

## Критичность обновления

Новая версия читается из опубликованных GitHub Releases. Чтобы плашка показала критичность и рекомендацию, добавьте в описание релиза одну строку:

```html
<!-- dagami-update: {"severity":"important","recommendation":"recommended"} -->
```

severity: normal, important или critical. recommendation: optional, recommended или required. Это описание необходимости установки, а не принудительная блокировка старого приложения: кнопка «Позже» остаётся доступной. Без метаданных плашка честно сообщает, что критичность не указана. По словам в тексте она не вычисляется.
