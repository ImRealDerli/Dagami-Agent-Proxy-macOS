Неофициальный форк [Dagami Agent Proxy](https://github.com/j46871417-ui/Dagami-Agent-Proxy). Здесь развивается версия для Mac: приложение со SwiftUI, профили подключения, запуск IDE и CLI через локальный мост, настройка DNS и подготовка совместимых версий Antigravity.

## Что нового в mac.28

Сетевой транспорт переведён на Rust (Tokio/rustls): TCP/TLS, выбор IPv6/IPv4, большие двусторонние потоки и ограниченные тайм-ауты. Добавлены безопасное переподключение HTTP CONNECT, резервирование адресов Smart DNS и понятные ошибки upstream. Интерфейс, профили, Keychain, квоты и патчи сохранены.

После обновления перезапустите приложения через Dagami. Старые сессии сохраняют прежний движок. Rust указан в настройках и подробностях новых сессий. Подробнее: [сетевой движок и ограничения](docs/NETWORK_ENGINE.md).

Для активности Codex проверьте hooks командой `/hooks`. Для Antigravity App/IDE подключите активность в настройках и перезапустите клиент. Квоты App/IDE используют внутренний интерфейс Antigravity, который может меняться: [описание мониторинга](docs/SESSION_MONITORING.md).

## Что умеет порт

- Хранит несколько профилей: прокси, Smart DNS или их сочетание. Из ссылки прокси разбираются адрес, порт, логин и пароль; пароль хранится в Keychain.
- Запускает поддерживаемые приложения через локальный мост. Для десктопных приложений перед запуском и патчем показывает открытые процессы и предлагает закрыть их или отменить действие.
- Настраивает DNS для выбранных доменов либо сетевых служб macOS. Есть сохранение прежних настроек и возврат.
- Помогает открыть вход через выбранный профиль. Для Antigravity CLI есть перехват исходной OAuth-ссылки и получение кода из отдельного браузера через Selenium.
- Различает Antigravity App и Antigravity IDE на базе VS Code. Для совместимых сборок есть подготовка, откат и кнопка «Починить IDE».
- Определяет ChatGPT Desktop. Если установленная сборка не подходит процессору Mac, показывает причину; веб-версию можно открыть отдельно через выбранный профиль.
- Сохраняет подробные ошибки в журнал. Ссылки с параметрами входа, пароли и коды скрываются.

Полный перечень изменений — в [CHANGELOG.md](CHANGELOG.md). Детали реализации и прежние заметки — в [docs/MACOS_TECHNICAL.md](docs/MACOS_TECHNICAL.md).

## Установка

Нужна **macOS 13 или новее**. Dagami собран для Intel и Apple Silicon; Python отдельно устанавливать не требуется. Для браузерного входа нужен совместимый Chrome, Edge, Brave или Chromium.

1. Откройте [выпуск mac.28 beta](https://github.com/ImRealDerli/Dagami-Agent-Proxy-macOS/releases/tag/v0.4.1-mac.28-beta).
2. Скачайте `Dagami-macOS-Universal.dmg`, откройте образ и перенесите `Dagami.app` в «Программы».
3. Запустите Dagami. Если macOS просит разрешить запуск приложения от неизвестного разработчика, проверьте источник загрузки и используйте штатное разрешение в «Системные настройки → Конфиденциальность и безопасность». Сборка подписана локальной ad-hoc подписью и не нотарифицирована Apple.
4. Если появляется окно активации Dagami, порядок получения ключа смотрите в [официальном проекте](https://github.com/j46871417-ui/Dagami-Agent-Proxy). Аккаунт Google/OpenAI и ключ Dagami — разные вещи.
5. Создайте профиль, выберите его и запустите нужное приложение из Dagami.

Вместо DMG можно скачать ZIP с тем же приложением. В выпуске также лежат полный архив исходников и `SHA256SUMS.txt`. Проверить скачанные файлы в Terminal:

```sh
shasum -a 256 -c SHA256SUMS.txt
```

Скачайте перечисленные в файле архивы в одну папку перед проверкой.

## Как выбрать подключение

**Прокси.** Вставьте полную ссылку в профиль, проверьте разобранные поля и сохраните. Выключенный флаг прокси сохраняет адрес и реквизиты, но отключает их использование.

**Smart DNS.** Выберите провайдера или задайте собственные DNS-узлы. DNS-only не меняет IP-адрес и не заменяет VPN. Результат зависит от доменов, которые обслуживает выбранный DNS, и правил самого сервиса.

Для повседневной работы начните с DNS по доменам: общий DNS браузера и остальных сайтов останется прежним. Если меняете DNS сетевой службы целиком, выбирайте активное подключение — Ethernet или Wi-Fi. Права администратора запрашиваются отдельно при записи системных настроек.

Профиль действует на управляемые сессии. Уже открытое приложение нужно закрыть и запустить заново через Dagami. Программы, которые игнорируют proxy-env и не имеют своего адаптера, могут потребовать другой способ подключения.

## Antigravity: App, IDE и CLI

Это разные клиенты. Выбирайте соответствующую карточку; вручную добавленная программа `custom_…` может использовать общий способ запуска.

Для **Antigravity IDE на базе VS Code** в mac.25 проверен сетевой патч официальной **IDE 2.6.0**. Он создаёт отдельную копию, направляет загрузку manifest и CLI через мост Dagami, увеличивает стандартный тайм-аут manifest до 30 секунд и передаёт исходные ссылки входа в тот же маршрут. Подпись копии проверяется. Оригинальная IDE сохраняется.

1. Если IDE не найдена, добавьте её `.app` вручную. Bundle ID распознаётся независимо от имени папки.
2. В карточке **Google Antigravity IDE** нажмите «Патч», затем «Запустить».
3. Если проблема появилась после подготовки, нажмите **«Починить IDE»**. Сохраните файлы перед подтверждением закрытия процессов. Dagami пересоздаст копию из установленного оригинала и проверит её; затем запустите IDE заново.
4. Чтобы вернуть обычный запуск, используйте «Откат».

Неизвестная версия загрузчика не патчится. Ремонт копии не устраняет отказ внешнего сервера, неверные реквизиты прокси или ограничения аккаунта.

Для **Antigravity App** и **CLI** действуют отдельные проверки совместимости. Вход CLI начинайте в новой сессии через Dagami. Пароль и подтверждение Google вводите сами в браузере. Selenium получает код только с разрешённой страницы возврата при совпадении OAuth state и отправляет его в ожидающий CLI. Начатый ручной ввод не перезаписывается. В комплекте ChromeDriver 156; для другой основной версии Chromium потребуется соответствующий драйвер.

## Обновление и хранение данных

Закройте прежний Dagami и замените приложение новой копией. Профили и состояние находятся в `~/.devproxy`, пароли прокси — в Keychain. Для обновления эти данные удалять не нужно.

После обновления начните новые управляемые сессии. Если изменился путь к Dagami или версия целевого приложения, пересоздайте соответствующий ярлык или подготовку. Учётные данные целевых приложений при обычном обновлении не сбрасываются.

## Если что-то не работает

Откройте журнал Dagami и найдите последнюю неудачную операцию. Для Antigravity есть также пункт «Проверить сервер IDE». Статус `running` сообщает о процессе, а не об успешном входе или доступности модели.

В [issue](https://github.com/ImRealDerli/Dagami-Agent-Proxy-macOS/issues) укажите версию macOS, процессор, версию Dagami и целевого приложения, режим профиля и шаги до ошибки. Приложите текст ошибки из журнала. Перед отправкой проверьте, что в нём нет личных данных. Полную ссылку прокси с паролем и OAuth-ссылки публиковать не нужно.

## Проверки и ограничения

Для mac.26 прошли 287 тестов с временными файлами, тестовыми процессами и loopback-серверами. Проверены целостность сборки и подпись приложения; для IDE 2.6.0 отдельно проверялись подготовка копии и откат. Это не проверка живых аккаунтов всех поддерживаемых сервисов. Работу входа, подписок, квот и регионального доступа нужно проверять отдельно. Проверка TLS-сертификатов сохраняется.

Universal относится к самому Dagami. ARM64-only приложение не запустится на Intel из-за прокси-патча. Для ChatGPT в таком случае есть отдельная веб-версия.

В журнале cliAuth видны этапы, но нет самого кода.

## Проверка версий и установка обновлений

Начиная с mac.26 Dagami проверяет публичные выпуски этого macOS-форка при запуске и затем раз в 6 часов. Бета-релизы учитываются. Автоматическую проверку можно отключить в настройках; там же есть ручная проверка. Подключение использует выбранный профиль, а без профиля — обычную сеть.

Если появилась новая версия, открывается окно с номером, описанием изменений, критичностью и рекомендацией автора выпуска. «Обновить» скачивает ZIP, сравнивает SHA-256, проверяет пакет, обе архитектуры и подпись, затем перезапускает Dagami. «Позже» откладывает напоминание на сутки. Самостоятельной установки без нажатия «Обновить» нет.

Если новая копия не подтвердит запуск, установщик возвращает предыдущую. Одна предыдущая копия сохраняется рядом с приложением для восстановления; старые копии, которые ещё используют процессы, не удаляются. Профили, Keychain, настройки DNS и сессии других приложений не сбрасываются. Для записи в папку Dagami нужны права текущего пользователя. Запущенную из DMG или App Translocation копию сначала перенесите в доступную папку. Проверка ad-hoc подписи подтверждает целостность пакета, а не нотарификацию Apple.
