# Dagami Universal

SwiftUI, macOS 13+, Universal2 для Intel и Apple silicon. Встроенный Python.org universal2 runtime. Профили, Keychain и системный DNS сохраняются при обновлении.

## Авторизация через профиль

Раздел «Авторизация» открывает отдельный Chromium/Chrome/Edge/Brave-профиль с тем же сетевым маршрутом, что выбран в Dagami. Пароли вводятся на официальных страницах сервисов; Dagami не собирает пароли ИИ-аккаунтов. Для веб-сервисов есть обычный браузерный вход и своя HTTPS-ссылка. Веб-сессия не заменяет вход в CLI.

Для Codex и Claude Code доступен штатный CLI-вход: запуск команды, временный перехват открытия браузера в окружении дочернего клиента и подхват ссылки из вывода. OAuth state, redirect_uri и callback сохраняются без изменения. Localhost callback не отправляется в upstream. Codex поддерживает режим кода устройства; его может потребоваться включить в настройках безопасности ChatGPT.

Официальная документация Codex: https://learn.chatgpt.com/docs/auth .

Режим «Подхват из приложения» отслеживает новые ссылки в свежих .log-файлах поддерживаемых клиентов (Codex, Claude, Gemini/AGY, Antigravity, Cursor, Windsurf, VS Code, OpenCode). Сначала включите наблюдение, затем начните вход в клиенте. Статическая страница входа, старый URL или лог нестандартного клиента не гарантируют успешный вход. «Найти ссылку» и ручная вставка доступны отдельно.

Поддерживаемые веб-провайдеры: Codex/ChatGPT, Claude, Gemini/Antigravity, DeepSeek, Qwen, Grok, Perplexity, Mistral, Microsoft Copilot, OpenRouter; для других сервисов предусмотрена своя HTTPS-ссылка. Автоподхват принимает ссылки только на разрешённые домены соответствующего сервиса. Нестандартные способы OAuth могут требовать отдельной интеграции.

Сессия входа живёт, пока работает Dagami. «Остановить сессию» закрывает принадлежащие ей браузер и login-процесс; уже сохранённые аккаунты клиента не удаляются. Ссылки и коды входа не записываются в журнал Dagami. Сам клиент может вести свой штатный журнал авторизации.

## Активация Dagami

Первый запуск требует ключ Dagami. В настройках можно заменить ключ или сбросить активацию с подтверждением. Сбрасывается только ключ Dagami; пароли прокси, профили и ИИ-аккаунты сохраняются. Текущая сессия входа через браузер закрывается.

## Подготовка Codex

«Приложения → Codex CLI / Codex Desktop → Патч» создаёт обратимый управляемый запуск через выбранный профиль. Установленный бинарник Codex, auth.json, sandbox, подписка и квоты не изменяются. «Откат» удаляет управляемую подготовку запуска. Вход выполняется штатным клиентом в разделе «Авторизация».

Для Antigravity сохранён патч совместимой приватной копии Mach-O x86_64. Оригинал не изменяется; неизвестные сигнатуры и ARM64 CLI не патчатся. Локальная подготовка не гарантирует доступ к модели на стороне сервиса.

## DNS и журнал

Для обычных страниц рекомендуется раздельный системный DNS: «DNS в системе → Исправить загрузку страниц в браузере». Обычный общий DNS восстанавливается с копией, Smart DNS остаётся доменам ИИ. Запись требует прав macOS. Журнал с ротацией находится в ~/.devproxy/journal. Ссылки официального репозитория и Mac-портера доступны в настройках.

## Сборка

Нужны Command Line Tools и Python.org universal2 Python 3.12 с сертификатами.

```
python3.12 -m pip install '.[macos-build]'
python3.12 tools/build_universal.py
python3.12 tools/build_dmg.py
```

Готовые файлы создаются в ../Release. Подпись ad-hoc, Developer ID/notarization отсутствуют. Для работы браузерной авторизации нужен установленный Chromium-совместимый браузер.

Повторный запуск IDE учитывает только процессы приложения. Браузер входа сохраняет свой маршрут, но не считается запущенной IDE.

Для Antigravity IDE откройте «Авторизация → Antigravity IDE → Настроить вход в IDE». После сохранения файлов подтвердите обновление и перезапуск. Затем нажмите «Начать вход» в Dagami и «Войти» в IDE: только свежая ссылка самой IDE завершает её вход. Gemini / Google AI — отдельный веб-вход. Остановка ожидания в Dagami не закрывает IDE и её браузер; полная остановка управляемой сессии закрывает их. Учётные данные остаются у клиента.

OAuth из буфера обмена работает только при активной сессии ожидания, включённом переключателе и совпадении выбранного профиля. Скопируйте свежую полную ссылку клиента после начала ожидания. Принимаются доверенный HTTPS-домен, client_id/state и callback клиента; произвольные ссылки не открываются, прочий текст не передаётся backend. Для CLI выберите «Antigravity CLI». Проверка маршрута использует тот же LocalTunnel и строгий TLS без отправки токенов. Smart DNS не заменяет VPN или исправный upstream и не гарантирует доступность аккаунта.

В mac.20 обновите подготовку через «Настроить вход в IDE» после сохранения файлов. Backend capture v2 включает передачу URL хосту (ANTIGRAVITY_VSCODE_HOST) и перехватывает исходную OAuth-ссылку прямо из backend. Копирование из браузера не требуется. Промежуточные страницы Google /v3/signin/accountchooser и /signin/oauth/.../consent повторно не открываются; для новой попытки нажмите «Войти» в клиенте заново. State, PKCE и callback не переписываются.

Antigravity CLI: выберите профиль и нажмите «Авторизация → Antigravity CLI → Открыть CLI с перехватом входа» либо запустите его из раздела «Приложения». CLI работает в отдельном Terminal с PTY; исходные OAuth-ссылки из stdout/stderr или BROWSER/open открываются автоматически через тот же LocalTunnel. Запуск через Dagami использует существующую подготовленную копию CLI, если она есть. Клавиатура, размер окна и код выхода сохраняются; буфер обмена не требуется. После обновления откройте новую управляемую CLI-сессию.

Перехват CLI в mac.20 накапливает многострочную ссылку целиком. Перед открытием проверяются client_id, state, callback, response_type, scope и PKCE. Первая строка длинного URL не считается отдельной ссылкой. Для новой попытки откройте новую управляемую CLI-сессию.

Antigravity CLI использует также официальный HTTPS callback https://antigravity.google/oauth-callback. Перехват сохраняет его без замены на localhost. Разрешение ограничено этим точным адресом для CLI; произвольные внешние callback не принимаются. Для IDE сохраняется локальный callback. После обновления откройте новую CLI-сессию через Dagami.

Для регионального Google-входа mac.20 обрабатывает отказ 403 шлюза Dagami на accounts.google.ru:443 одним повтором к общему Google endpoint accounts.google.com:443 через тот же настроенный upstream. Исходный HTTPS-домен accounts.google.ru, SNI и HTTP Host остаются внутри неизменённого TLS-туннеля; сертификат проверяет клиент. SID и OAuth URL не переписываются. Если повтор не проходит, ошибка возвращается без прямого подключения. Исключение не применяется к другим прокси и доменам.

В mac.20 отдельный браузер Antigravity CLI управляется Selenium WebDriver, подключённым только к его изолированному профилю. После ручного входа Google код с https://antigravity.google/oauth-callback принимается только при совпадении OAuth state и передаётся в CLI с Enter, когда CLI ожидает код. При начатом ручном вводе автоматика не вмешивается. Код не записывается в журнал. В комплекте ChromeDriver 156 для mac-x64/mac-arm64 и Python-зависимости; подготовка зависимостей: tools/prepare_webdriver.py. Для браузера другого major требуется соответствующий драйвер.

Для десктопных приложений запуск и патч проверяют процессы по путям bundle и потомкам. «Закрыть процессы» требует предварительного сохранения данных; при отказе закрытия действие не продолжается. CLI не закрываются этим диалогом.

Ошибки в журнале содержат полные traceback и stderr; параметры URL, пароли, ключи и коды скрываются. В меню Antigravity есть «Проверить сервер IDE»: это отдельная проверка публичного release manifest через выбранный профиль. Необязательная блокировка автообновлений не блокирует CLI/IDE manifest-хосты, необходимые для установки.

В mac.21 ChatGPT Desktop обнаруживается отдельно от Codex, включая ChatGPT.app с bundle ID com.openai.codex. Кнопка «Патч» создаёт обратимый ярлык через Dagami; бинарные файлы и аккаунт сохраняются. Для установленной Electron-версии применяются --proxy-server, loopback bypass, отключение QUIC и proxy-env для backend. Старые процессы закрываются только после подтверждения. Для нативной версии upstream-прокси не объявляется поддержанным: доступен DNS-only при настроенном системном DNS.

В mac.22 несовместимая архитектура показывается в карточке приложения до запуска и патча. ARM64-only ChatGPT на Intel запустить нельзя. Кнопка «Веб-версия» открывает https://chatgpt.com/ в отдельном окне совместимого Chrome/Edge/Brave/Chromium через текущий профиль Dagami. Данные браузера находятся отдельно в ~/.devproxy/web-chatgpt с отдельной папкой для каждого профиля. Обычный браузер и нативное приложение не изменяются. Доступна также карточка «ChatGPT — веб-версия».

mac.23 разделяет Antigravity App и Antigravity IDE (VS Code). IDE определяется по com.google.antigravity-ide, исполняемый файл берётся из Info.plist. Для установки вне стандартной папки добавьте .app вручную: будет выбрана встроенная карточка IDE. Существующие ручные записи сохраняются; неактивные дубликаты скрываются.

Кнопка «Патч» для официальной Antigravity IDE 2.6.0 создаёт отдельную подписанную копию с проверенным SHA-256 загрузчика. Она направляет fetch manifest/загрузку CLI через тот же профиль Dagami и увеличивает стандартный тайм-аут manifest до 30 секунд. Сертификаты проверяются; прямого резерва нет. OAuth openExternal передаётся аутентифицированному локальному мосту с проверкой исходной ссылки. Это сетевой патч IDE; он не объявляет доступным аккаунт и не подменяет отдельно устанавливаемый CLI. Неизвестная версия не патчится. После подготовки запускайте карточку Google Antigravity IDE, а не старую custom-запись. Откат удаляет только подготовленную копию, оригинал и профили остаются.

mac.24: кнопка «Починить IDE» пересоздаёт подготовку Antigravity из установленного оригинала, даже если прежняя копия повреждена. Перед действием предлагается закрыть процессы. Новая копия проверяется по SHA-256 и codesign; при ошибке сохраняется прежняя запись. Настройки, аккаунты и оригинал не удаляются. Сетевые ограничения сервера этим ремонтом не объявляются устранёнными. После ремонта нажмите «Запустить».
